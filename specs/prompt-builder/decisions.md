## Future Room Type Expansion

Room types should continue to be organized by residential category instead of becoming one long flat list.

Likely future room types:

Living Spaces:

- Family Room
- Breakfast Nook
- Library

Service Spaces:

- Mud Room
- Walk-in Closet

Entertainment Spaces:

- Wine Cellar
- Recording Studio

Private Spaces:

- Nursery

These are not required for the current implementation, but the room type structure should remain easy to extend.
