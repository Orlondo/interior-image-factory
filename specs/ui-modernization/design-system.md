## Accent Usage

Accent color should only appear on:

- Selected cards
- Selected chips
- Generate button
- Focus states
- Active tabs

Everything else remains neutral.

## Radius

Small: 10px
Medium: 16px
Large: 20px

## Shadows

Very subtle.

Avoid dramatic shadows.

## Typography

Headings:
600-700 weight

Body:
400-500 weight

Avoid excessive font sizes.

## Spacing

Use an 8px spacing system.

Examples:

8px
16px
24px
32px
48px

Avoid arbitrary spacing values.
